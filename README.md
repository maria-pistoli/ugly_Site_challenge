# ugly_Site_challenge — eΚλάση™

Μια εσκεμμένα απαίσια παρωδία πλατφόρμας ασύγχρονης εκπαίδευσης, για το Ugly Site Challenge.
Όλα τα μαθήματα και οι διδάσκοντες είναι φανταστικοί.

- 6 ψεύτικα μαθήματα. Για να ανοίξουν οι διαφάνειες και το υλικό, πρέπει να απαντήσεις σωστά σε 5 ερωτήσεις. Ένα λάθος σε στέλνει από την αρχή.
- Κουμπιά που φεύγουν, απαντήσεις που αλλάζουν θέση, marquee, blink, ουρά πίσω από τον κέρσορα.
- Ψεύτικα loading που φτάνουν στο 99% και πέφτουν πίσω στο 37%, και CAPTCHA-παρωδία.

## Τρέξιμο

Είναι στατικό site (HTML/CSS/JS), χωρίς build:

```bash
python -m http.server 8765
```

και άνοιξε το http://localhost:8765. Ή απλά άνοιξε το `index.html` με διπλό κλικ.

Δομή: `index.html`, `css/style.css`, `js/data.js` (μαθήματα, ερωτήσεις, διαφάνειες), `js/app.js` (όλη η λογική).
